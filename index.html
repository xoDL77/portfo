Projects & Labs

Agentic AI Vulnerability Assessment Tool

Python · Claude Agent SDK · Personal Project

Built an autonomous vulnerability-assessment agent that can be pointed at a single host or an entire subnet and left to run a scoped security assessment end to end, auto-generating a findings report when it's done. The agent enforces a strict tool allow-list and validates every target against an authorized IP scope before it's allowed to act, so it can't wander outside the boundaries it was given — scan data and secrets are stored encrypted at rest. It runs as a managed background service with start-on-boot and auto-restart-on-failure, and has been iterated on and version-controlled across multiple releases. Building the guardrails turned out to be the harder and more interesting problem than building the automation itself.

Active Directory Attack Chain

kerbrute · Impacket · Active Directory · Home Lab

A home-lab exercise in chaining together a full Active Directory attack path instead of testing each technique in isolation. Started with unauthenticated username enumeration via kerbrute's Kerberos pre-authentication timing, then used Impacket to test the recovered accounts for AS-REP roasting — accounts with Kerberos pre-authentication disabled that hand back a crackable ticket to anyone who asks. From there, checked the domain's LDAP signing configuration and confirmed it wasn't enforced, which is a precondition for an NTLM relay attack. Walking one identity from anonymous enumeration to a relay-ready misconfiguration made it obvious why each of these individually "minor" settings compounds into a real path to compromise.

WPA2/PMKID Capture & Offline Cracking

Flipper Zero · ESP32 Marauder · Aircrack-ng · Home Lab

Wireless security testing against a personal lab network, aimed at going beyond just capturing a handshake and actually recovering the key. Used a Flipper Zero with an ESP32 Marauder board to profile nearby SSIDs, BSSIDs, channels, and encryption types, then forced a connected client to reassociate with a deauthentication frame to capture both the WPA2 4-way handshake and the PMKID to a .pcap file. Ran the capture through Aircrack-ng against a wordlist offline, and recovered the pre-shared key on a lab network deliberately configured with a weak passphrase. It's a fast, concrete way to demonstrate why a dictionary-crackable Wi-Fi password is a real vulnerability, not just a theoretical one.

RFID/NFC Badge Cloning

Flipper Zero · HID Prox (T5577) · MIFARE Classic · MFKey32 · Home Lab

Physical access control testing on two of the most common badge technologies still in wide use: low-frequency HID Prox and MIFARE Classic. Cloned a HID Prox credential onto a writable T5577 tag, then separately captured MIFARE Classic authentication traffic and recovered the per-sector keys with MFKey32, a nonce-based key-recovery technique. Combined both onto a single emulated fob capable of presenting either credential, using only a handheld reader/writer and no access to the original badge's backend system. The exercise is a reminder that a lot of physical access control still relies on credential technologies that were never designed to resist cloning.

Burp Suite Web/API Testing

Burp Suite · Web/API Security · Home Lab

Web application and API testing against intentionally vulnerable lab targets, focused on server-side trust boundaries rather than surface-level input validation. Used Burp Suite to intercept and modify requests, confirming a server-side request forgery by redirecting a vulnerable parameter to an attacker-controlled callback listener and watching the target make the outbound request itself. Separately tested authorization at the object level — not just the endpoint level — by diffing API responses between a low-privilege account and an admin account for the same resource IDs, which surfaced a broken object-level authorization issue letting one account reach another's data. Both findings map directly to entries on the OWASP API Security Top 10, and reinforced testing "can this identity reach this specific object," not just "can this identity reach this endpoint."

Secure Self-Hosted Minecraft Server

Ubuntu · AMP (CubeCoders) · Cloudflare Zero Trust · Nginx · Personal Project

Wanted to run a Minecraft server for friends without paying for a hosted Realm, without exposing a home IP address to the internet, and without handing out one shared admin password. Self-hosted the server with CubeCoders AMP on a personally managed Ubuntu box, put the web management panel behind an Nginx reverse proxy with a real TLS certificate on a private subdomain, and tunneled both the web and game traffic outbound so no public port ever has to be opened on the home network. In front of the management panel sits a Zero Trust access gate — Cloudflare Access — that only lets pre-approved email addresses in, and only after a one-time passcode, before anyone reaches a login screen at all. Friends get their own limited role (start/stop the server, manage the whitelist) through the app's built-in access controls, while full admin stays with one account — the same layered-access pattern used to protect much higher-value internal tools.

Uniform Random Apple Shortcuts Password Generator

Apple Shortcuts · iOS/macOS · Personal Project

Apple's built-in password generator looked random at a glance, but it always produces the same fixed shape — a set length, exactly one digit, one uppercase letter, two hyphens, and lowercase everywhere else. That fixed structure quietly shrinks the real keyspace: Apple advertises around 71 bits of entropy, but a known, unchanging format gives an attacker a big head start over truly random guessing. Built a password generator in Apple Shortcuts that instead samples every character independently from a 75-character pool of letters, digits, and symbols, with no positional pattern at all, plus input guardrails that explain in plain terms why short passwords are a bad idea before letting you generate one. A 17-character password from this generator works out to roughly 106 bits of entropy — about 7.5×1031 possibilities — versus the fixed-format original, using nothing but Apple's own visual scripting tool.
